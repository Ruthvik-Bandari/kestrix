# Python package (`src/kestrix`)

- Run `uv run pytest`, `uv run ruff check src tests scripts`, `uv run ruff format --check src tests scripts` and `uv run mypy`. Add dependencies through `uv` so `uv.lock` stays authoritative.
- The module functions are shared by the CLI and the FastAPI API. Keep each `cli.py` and `api.py` thin; no business logic in adapters.
- Load YAML and JSONL only through `core/safe_load.py`. Bound file size, line length and nesting. Never `pickle`, `eval` or `exec` imported content.
- Validate envelopes with Pydantic and an explicit `schema_version`.
- Do not implement a Python matcher as a stand-in for Elasticsearch. Matching claims come from replay on the pinned engine; tests that need it carry `@pytest.mark.engine`.
- Return explicit domain outcomes (`repaired`, `unchanged`, `abstained`, `unsupported`, `insufficient_evidence`, `engine_unavailable`) and raise `Rejected(Reason, detail)` for invalid input; never an empty result for an error.
- Outbound requests go through `core/netguard.check_url`.
- Hash artifacts with SHA-256, write to a temp path, then atomically rename (`core/evidence.py`).
- Tests use synthetic fixtures in the repo. Bundled detect cases are generated by `scripts/build_detect_cases.py`; regenerate rather than hand-edit. Never read `data/raw/` or `data/locked/`.
- Never log, return or write secrets or raw event payloads to evidence.
