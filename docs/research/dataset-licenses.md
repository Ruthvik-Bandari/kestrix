# Dataset license manifest (code-vulnerability ML, ADR 0005 part 3)

This manifest lists every dataset named in the [ML plan](code-vuln-ml-plan.md), with its license, its URL and
our usage tier. It is built from that plan. The pinned revisions and acquisition checks are in
[`docs/data/sources.md`](../data/sources.md). This page belongs in `docs/data/vul/LICENSES.md` once that
directory exists. It is not legal advice.

**Usage tiers:**

| Tier | Meaning |
| --- | --- |
| train | May be used to train models. Weights shipped with Kestrix use only functions from permissively licensed repositories, checked per repository. |
| dev | Development and threshold selection only; never training. |
| eval-only | External evaluation target. Downloaded at evaluation time, never vendored into this repository, never trained on. |
| baseline | A detector we compare against, not data. |
| reference | Read for method (labelling rules, paired evaluation); no data used. |
| not used | Not downloaded or used. |

**Rules that apply to every row:**

- A dataset's license covers the compilation, not the mined code. Every sample keeps `source`, `repo`,
  `repo_license` and `cve/ghsa` columns.
- Weights shipped with Kestrix (Apache-2.0) train only on functions from repositories licensed MIT, BSD, Apache
  or ISC, checked per repository by SPDX license. Their data card carries the CC BY 4.0 attributions.
- No labels generated by commercial models are used for training.
- A dataset may move to a less restrictive tier only after its license is checked again and this page is
  updated in the same change.
