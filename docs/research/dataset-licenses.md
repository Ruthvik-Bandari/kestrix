# Dataset license manifest (code-vulnerability ML, ADR 0005 part 3)

This manifest lists every dataset named in the [ML plan](code-vuln-ml-plan.md), with its license, its URL and
our usage tier. It is built from that plan. The pinned revisions and acquisition checks are in
[`docs/data/sources.md`](../data/sources.md). This page belongs in `docs/data/vul/LICENSES.md` once that
directory exists. It is not legal advice.

**Usage tiers:**

| Tier | Meaning |
| --- | --- |
| train | May be used to train models. Weights shipped with Kestrix use only functions from permissively licensed repositories, checked per repository. |
| dev | Development and threshold selection only; never training. |
| eval-only | External evaluation target. Downloaded at evaluation time, never vendored into this repository, never trained on. |
| baseline | A detector we compare against, not data. |
| reference | Read for method (labelling rules, paired evaluation); no data used. |
| not used | Not downloaded or used. |

**Rules that apply to every row:**

- A dataset's license covers the compilation, not the mined code. Every sample keeps `source`, `repo`,
  `repo_license` and `cve/ghsa` columns.
- Weights shipped with Kestrix (Apache-2.0) train only on functions from repositories licensed MIT, BSD, Apache
  or ISC, checked per repository by SPDX license. Their data card carries the CC BY 4.0 attributions.
- No labels generated by commercial models are used for training.
- A dataset may move to a less restrictive tier only after its license is checked again and this page is
  updated in the same change.

## Email benchmark corpora (`kestrixmailbench`)

The email accuracy benchmark ([`mail-benchmark.md`](mail-benchmark.md)) uses the corpora below to measure `kestrix.mail` and to learn finding weights. The tiers are the ones above, with one addition: **eval+train** means used both to evaluate and to learn the benchmark's weights. The owner decided to use every license-checked corpus this way, including the two with no stated license. This is not legal advice.

| Dataset | License | URL | Tier | Notes |
| --- | --- | --- | --- | --- |
| Nazario phishing corpus (raw mbox files 2005-2025) | CC BY 4.0, per the author's README and `LICENSE.txt` | <https://www.monkey.org/~jose/phishing/> | eval+train | **Attribution required**: Nazario, J., *Phishing corpus*. Hand-classified from one personal inbox, so it may hold errors; mailboxes after the early ones are not anonymized, so messages stay on the cluster. |
| SpamAssassin public corpus (`easy_ham`, `easy_ham_2`, `hard_ham`, `spam`, `spam_2`) | No license stated | <https://spamassassin.apache.org/old/publiccorpus/> | eval+train | Copyright of the message text stays with the original senders (corpus readme). Used for research by the owner's decision. Not redistributed; only aggregates are published. |
| Enron email dataset, May 7 2015 release | No license stated | <https://www.cs.cmu.edu/~enron/> | eval+train | Real employees' mail with personal information. Only a seeded sample (20,000 messages) is used. It stays on the cluster; no address, subject or body is reported. Used for research by the owner's decision. |
| TREC 2007 Public Spam Corpus | Application and agreement required | <https://trec.nist.gov/data/spam.html> | not used yet | The owner is applying. The benchmark takes a new source in `src/kestrixmailbench/sources.py` with no other change. |
| Synthetic messages | Generated for this repository (Apache-2.0) | `src/kestrixmailbench/synthetic.py` | eval only | Patterns the corpora lack (Russian casino spam, gift-card and payment-change BEC, link and attachment tricks). Reported as its own source, never pooled and never used to learn weights. |

**Rules for these corpora:**

- Raw messages live only under `/scratch/$USER/kestrix/mailbench/` on the cluster (directories 0700, files 0600). They are never copied to a laptop or committed.
- Reports, logs and the committed manifest hold counts, rates, intervals, finding-id frequencies, learned weights, and archive SHA-256 values. No body, address or subject is printed.
- The `acquire` step records URL, size, SHA-256 and download time per file (trust on first use); every later stage re-verifies against that manifest.
- `/scratch` is purged on the first Tuesday of each month (next: 2026-11-03). Downloads are reproducible from the manifest.

## Code accuracy benchmark (`kestrixcodebench`)

The code benchmark ([`docs/benchmarks/cvefixes.md`](../benchmarks/cvefixes.md)) measures `kestrix-scan` on the vulnerable and fixed versions of files from CVE fix commits. It reuses the data that `kestrixvul` already acquired (nothing new was downloaded) and adds baseline scanners. This is not legal advice.

| Item | License | Role | Notes |
| --- | --- | --- | --- |
| CVEfixes v1.0.8 | Data CC BY 4.0; collection code MIT | eval (dev now, locked test later) | **Attribution required**: Bhandari, Naseer and Moonen (2021), *CVEfixes*, PROMISE '21. Only the aggregate counts, rates and rule ids are published; the mined files stay on the cluster and keep each project's own license. |
| GitHub Advisory Database fix commits | Data CC BY 4.0 | eval (dev now, locked test later) | **Attribution required**: GitHub Advisory Database, <https://github.com/github/advisory-database>. Fix commits mined by `kestrixvul` from the public repositories. |
| Bandit 1.9.4 | Apache-2.0 | baseline (Python) | Installed from PyPI into a private virtual environment on the cluster. |
| ESLint 9 with `eslint-plugin-security` 4.2.0 | MIT; Apache-2.0 | baseline (JavaScript, TypeScript) | Installed with npm on the transfer node into a private prefix; run offline on the cluster's Node 22 module. Parser: `typescript-eslint` (MIT) with `typescript` (Apache-2.0). |
| Semgrep CE with the registry rules | Semgrep Rules License (not OSS) | **not used** | The registry rules' license restricts this use, and no OSS-licensed local ruleset was available, so Semgrep was skipped. |

Raw files stay under `/scratch/$USER/kestrix/codebench/` (directories 0700, files 0600). Reports hold counts, rates, intervals and rule ids only.
