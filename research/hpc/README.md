# HPC jobs

Slurm job scripts for the Northeastern Explorer cluster. See `docs/research/hpc.md` for access, the
hardware-by-task table and cluster constraints.

One folder per track: `common/` (environment setup, GPU smoke test), `detect/` (Sigma detection repair:
acquire, QC, replay, B2, M1), `codebench/`, `iac/`, `linkfile/`, `mail/` and `vul/`.
